# Site kits

Integrations that wrap the tag for specific site stacks (DEL-09, M3b-07):

- `react/`: `@adengine/react` with `<AdSlot/>` and a route-change hook.
- `wordpress/`: plugin with a block, shortcode, settings page and ads.txt.

They are built with their own tooling (npm, Composer), not Gradle.
